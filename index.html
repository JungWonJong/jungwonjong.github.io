스텔라이브 멤버가 등장하는 비공개·비상업 개인 팬 게임으로, 스텔라이브의 공식 활동과 무관하며 출시 계획은 없습니다. 2차 창작 가이드라인의 ‘협의 없는 개인 홍보 사용 금지’ 조항에 따라, 포트폴리오에서는 캐릭터를 모자이크 처리했습니다.

구간 바로가기

처음에는 100호점까지 확장하는 경영 게임이었습니다. 외부 플레이어의 “무엇을 하는 게임인지 모르겠다”는 피드백을 계기로, 가게 하나에서 멤버와 함께 일하며 친해지는 경험을 목표로 다시 설계했습니다.

튜토리얼 진행 조건 변경

호감도를 기다리던 단계를 없애고, 직접 행동하며 진행하도록 바꿨습니다.

기존에는 3분마다 방문하는 유니의 호감도를 39에서 80까지 올려야 했습니다. 이 단계에만 약 21분이 걸렸고, 다음 방문까지 남은 시간 표시를 추가한 뒤에도 기다림은 그대로였습니다.

게임 전체의 목표를 다시 정한 뒤, 호감도 누적 단계와 금화 8,000·상품 6종 진열 목표를 없앴습니다. 새 튜토리얼은 각 행동을 한 번씩 해 보면 다음 단계로 진행합니다.

  • 멤버와 대화 1회
  • 상품 구매 또는 교환 1회
  • 선물 1회

사람의 완료 시간은 미리보기와 대사 읽기 시간을 바탕으로 추정했습니다. 봇은 대사 읽는 시간을 4초로 설정했습니다. 개편 후 외부 플레이 테스트는 아직 진행하지 않았습니다.

질문 · 무엇이 실제 원인인가

추측을 멈추고, 같은 조건에서 다시 쟀습니다.

여행 창을 열면 노트북이 느려졌습니다. 첫 수정은 테스트를 통과했지만 실제 플레이에서는 문제가 재발했습니다. AI는 금빛 테두리를 원인으로 추측했으나, 전후 측정을 통해 1초마다 그림을 교체해 창 전체를 다시 그리던 공통 갱신 코드를 확인했습니다.

창을 닫은 비교 화면은 24ms에서 23ms/초로 거의 같았습니다. 같은 그림과 도움말을 반복해서 교체하던 동작을 고친 뒤에는 테두리를 없애도 작업 시간이 더 줄지 않아, 테두리 사전 생성 도구는 적용하지 않았습니다.

Edge 성능 기록에서 같은 게임 상태·화면 너비 1,366px·CPU 처리 4배 감속 조건으로 비교했습니다. 각 화면을 6초간 기록해, 브라우저에 기록된 GPU 작업 시간을 1초당 평균값(ms)으로 계산했습니다.

테스트와 직접 플레이를 어떻게 나눴나요?

자동 테스트 약 1,890개로 규칙을, 시드 30개의 플레이 봇으로 엔딩 날짜와 자금 고갈을, 세 가지 화면 가로폭의 캡처로 겹침·잘림을 점검했습니다. 별도로 설치판을 며칠씩 플레이하며 발견한 문제 20건을 날짜와 현상으로 기록했습니다.

외부 플레이어 3명은 모두 엔딩에 도달했고, 이들의 피드백은 방향 전환의 계기가 됐습니다. 테스트 통과와 재미·편의성은 구분해 확인했습니다.
